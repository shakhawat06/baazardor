# 🛒 Baazardor — Grocery Price List

**Baazardor** is a grocery price tracking website built with Next.js that helps users explore everyday grocery products and check their latest available market prices in one place. The goal is to make grocery price information accessible, simple, and convenient.

## ✨ Core Features

- **🛍️ Product Price List** — Browse grocery products with their latest available prices.
- **📂 Category-Based Browsing** — Explore products by category.
- **💰 Price Comparison** — Compare prices of different grocery products.
- **📱 Responsive Design** — Access the website on desktops, tablets, and mobile devices.
- **🔄 Latest Price Information** — View recently updated product prices when new data is available.
- **📦 Product Details** — View product information, including names, categories, and prices.
- **⚡ Fast Performance** — Take advantage of Next.js rendering and data-fetching capabilities.
- **🇧🇩 Local Grocery Focus** — Designed to help users in Bangladesh explore everyday grocery market prices.

## 🛠️ Technologies Used

- **[Next.js](https://nextjs.org/)** — React framework for building the website.
- **[React](https://react.dev/)** — Component-based user interface.
- **[JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)** — Application logic.
- **[Tailwind CSS](https://tailwindcss.com/)** — Styling and responsive layouts.
- **REST API / Fetch API** — Retrieving product and price data.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm, yarn, pnpm, or bun
- Git

### Installation

**1. Clone the repository**

```bash
git clone git@github.com:shakhawat06/baazardor.git
```

**2. Navigate to the project directory**

```bash
cd baazardor
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the website**

Visit [http://localhost:3000](http://localhost:3000) in your browser.
